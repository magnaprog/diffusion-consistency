# Documentation revisions, 29 October 2026

The three source files here preserve the exact active versions from commit
`3c197eef6e50be8c070e5690d0d0a75ef32ac312`. They are historical copies for source
verification, not modules to import or execute. The current versions clarify
the toy results file, the flat sequence of years accepted by the scoring helper,
and the distinction between diffusion timesteps and array indices.

`MANIFEST.json` records the previous and current hash for each file. The source
validator pins this manifest, the base commit and the three filenames. It checks
both file identities and compares Python syntax after removing docstrings.
Comments and docstrings can differ; all other syntax must agree. These checks
authenticate the specified revisions, not arbitrary later edits or the scientific
correctness of their explanations.

After this step, the toy exporter and scoring helper continue through the
[earlier documentation map](../../documentation_source/README.md). The scoring
helper also retains its [accepted-source mapping](../../accepted_source/README.md)
when the paper verifier resolves the original execution version. The schedule's
previous version already has the hash in the original evidence and passes through
directly. The earlier manifests, source copies and scientific records retain
their original bytes.

The public exporter validates the same bytes it copies, including this manifest
and the three previous sources. New experiments record the current source hashes
normally. The repository MIT license covers these historical copies.
